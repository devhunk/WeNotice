# WeNotice

Windows 微信桌面通知应用，当前版本 **0.2.0**。

工作目录入口和归档位置见 [项目目录说明](../README.md)。

## 运行

从项目根目录双击 `启动WeNotice.cmd`，或运行 `../releases/win-unpacked/WeNotice.exe`。保留整个 `win-unpacked` 文件夹，包括原版 `electron.exe`、读取组件和微信跳转组件。

先登录微信，再在设置中点击“一键连接微信”。自动连接会检测账号、获取并实际验证数据库密钥，再通过系统加密存储保存。读取组件随包提供，无需后台运行 WeFlow。

关闭设置窗口后仍会在托盘监听；完全退出请使用托盘菜单。

0.2.0 独立便携测试包位于 `../releases/WeNotice-0.2.0-customization/win-unpacked/WeNotice.exe`。先从托盘退出旧版，再启动测试包；原有 `releases/win-unpacked` 不受影响。必须保留整个便携目录。

## 自定义设置

主界面使用暖白/陶土橙配色，支持浅色、深色和跟随系统；侧栏可折叠。界面主题与通知主题分别保存。所有偏好均通过界面调整，不提供导入导出。

| 页面 | 可调整内容 |
| --- | --- |
| 通知外观 | 头像大小与圆角、标题/正文字号、卡片圆角、内边距、颜色、不透明度、固定/自适应宽度、最大行数、屏幕边距、目标屏幕、头像/时间/数量/正文显示；含实时预览 |
| 通知行为 | 显示时长、六个停靠位置、悬停暂停、点击打开聊天或关闭、同会话待显示消息合并、队列和历史上限、时段免打扰 |
| 通知规则 | 私聊/群聊、精确会话 ID、包含/排除关键词，以及提醒、外观、位置、时长和免打扰例外；支持复制、排序与测试 |

**微信在前台时隐藏通知默认开启。** 当前活动窗口属于 `Weixin.exe` 或 `WeChat.exe` 时不弹窗，但继续读取消息和记录历史；切回微信后会在下一次检查时关闭已有弹窗、清除真实消息队列，每 250ms 检查一次。切离后不补弹。仅后台运行、最小化和托盘状态不会抑制。手动测试通知不受此开关限制。

规则自上而下首条命中生效；不同条件同时满足，包含词任意命中即可，排除词任意命中则跳过本条规则。关键词对原始正文进行不区分大小写的字面匹配，不支持正则。规则未覆盖的字段继承全局；“单独设置”可逐项覆盖外观。重要会话可分别绕过时段免打扰与微信免打扰，不能绕过全局关闭、前台抑制、自发/未知方向消息、折叠会话或黑白名单。

免打扰时段按本地时间执行，起点包含、终点不包含；跨午夜时段按开始日选星期。例如勾选周一 22:00–08:00，覆盖周一晚至周二早。被过滤的消息不在结束后补发。

保存外观、规则等偏好不会重连数据库或重置消息基准；队列出队时使用最新规则，已经显示的通知保留本次参数。改变连接字段或密钥才会重连；改变补查间隔只更新定时器。关闭全局通知会暂停监听。屏幕断开时临时回退主屏。

旧配置首次加载前会备份为 `%APPDATA%/WeNotice/settings.json.pre-0.2.0.bak`，保存时保留加密密钥；异常配置备份为 `settings.json.invalid.bak` 并显示提示。恢复偏好默认值不清除账号和密钥。回退旧版时，先完全退出新版，再用迁移备份恢复 `settings.json` 后启动旧包。

## 当前功能

- 自动检测本机微信账号目录，支持多账号选择、手动配置和密钥失效后重新获取。
- 独立后台读取，通过命名管道与定时补查发现新消息。
- 过滤自己发送的消息、首次启动前的历史消息及未知发送方向的消息。
- 支持私聊、群聊、免打扰、白名单、黑名单和同会话通知合并。
- 消息正文作为主要内容，联系人和时间作为辅助；通知尺寸随内容长度调整。
- 点击普通通知调用本机微信定位相应聊天，测试通知打开本应用。
- 支持托盘、开机启动、暂停、位置、显示时长和最近通知列表。

## 开发

环境：Windows x64、Node.js 和 npm。当前工作副本已包含开发依赖。

```powershell
npm ci                  # 新检出的源码首次安装依赖时运行
npm run dev             # 开发预览
npm test                # 自动化测试
npm run build           # 类型检查和生产编译
npm run check:ui        # 隔离 Electron 集成检查和截图；先 build，不读取真实账号
npm start               # 运行已编译源码
npm run dist:win        # 编译并打包 Windows 安装包
npm run dist:portable   # 编译并打包免安装目录，校验 ASAR 内容
```

安装包和免安装目录统一输出到 `../releases/`。打包前先从托盘退出正在运行的发布版，避免文件占用。主进程修改后需重启开发程序，渲染页面支持热更新。

## 配置与验证记录

配置保存于 `%APPDATA%\WeNotice\settings.json`，密钥通过 Electron `safeStorage` 加密。最近通知只保存在内存，退出清空。应用不写入微信数据库。

读取和密钥组件来自本机 WeFlow 6.3.2，构建时必须保留 `resources/wcdb/`、`resources/key/`，并随包提供原版 Electron 宿主。原生组件实现源码不在本项目中，接口约定见 [COMPONENT_CONTRACT.md](docs/COMPONENT_CONTRACT.md)。参考源码、修复工具及组件备份在 `../archive/WeFlow/`，本项目的历史验证报告和恢复备份在 `../archive/WeNotice-repair/`。

此前已验证本机读取、监听及微信聊天定位组件；另一账号的新消息触发实际弹窗并点击跳转的完整链路仍需实机验收。数据库兼容性依赖组件及微信版本，详见 [验收说明](docs/ACCEPTANCE.md)。界面截图使用模拟消息，保存在 `docs/ui/`。

0.2.0 本轮验证：43 项自动测试通过；13 项隔离 Electron 检查通过，覆盖主题、预览保存、规则编辑、最小窗口、前台抑制、队列清除、悬停暂停、点击关闭及长内容尺寸。Win32 API 已在本机成功查询活动进程；微信前台切换场景使用注入状态，未伪装成真实微信验证。检查报告和截图位于独立包目录的 `verification/`。多屏物理拔插、其他 DPI、真实微信新消息和长时间运行尚未完成。
