# Windows 实机验收

自动化测试不是以下实机测试的替代。当前未完成下列验收，不应标记为稳定版。

- [ ] 干净 Windows x64 安装、首次启动、卸载、重新安装。
- [ ] 不配置 DLL/密钥也能弹出测试通知，错误信息可理解。
- [ ] 配置有效组件和账号，建立连接；首次启动不弹历史。
- [ ] 新私聊、群聊、中文/表情、图片/语音/视频摘要正确。
- [ ] 同秒连续消息、未读数不变、消息跨批次时不漏不重。
- [ ] 自发、免打扰、折叠、白/黑名单规则正确；状态未知可诊断。
- [ ] 停止/暂停期间无迟到弹窗；继续后建立新基线。
- [ ] 微信退出再登录、数据库暂时不可用、管道断开后恢复。
- [ ] 主窗口关闭仍监听，托盘退出完整清理，第二次启动不重复实例。
- [ ] 通知快速连续到达、同会话队列合并、旧 ID 关闭事件安全。
- [ ] 六个停靠位置、125%/150%/200% DPI、显示器拔插和任务栏避让。
- [ ] 微信真实前台/后台/最小化/独立聊天窗口切换：前台关闭弹窗并清空队列，切离不补弹；历史仍记录。
- [ ] 真实会话关键词规则、跨午夜时段与重要会话例外；保存偏好不重连、不重置消息基准。
- [ ] 原生玻璃正常；原生能力不可用时回退不黑屏、不递归捕获自身。
- [ ] 自动关闭、点击通知、无焦点显示、全屏应用下的行为可接受。
- [ ] 锁屏/解锁、休眠/唤醒、至少 8 小时运行；检查内存与 CPU。
- [ ] 配置中无明文密钥；日志无正文/密钥；最近通知退出清空。
- [ ] 开机启动可启用/关闭，后台启动不弹设置页。

建议在本机记录：Windows 版本、微信版本、组件版本、GPU/驱动、缩放比例、场景、预期/实际、发生时间。不要分享聊天正文或密钥。
