# 通知样式与尺寸适配

## 官方参考与适配范围

- [微信官方 WeUI](https://github.com/Tencent/weui)：由微信官方设计团队提供，面向微信内网页。
- [WeUI 设计资源](https://github.com/weui/weui-design)：微信原生视觉体验的设计参考。
- [WeUI 浅色主题变量](https://github.com/Tencent/weui/blob/master/src/style/base/theme/vars/light.less)：品牌绿 `#07c160`、白色背景、主文本 `rgba(0,0,0,.9)`、次文本 `rgba(0,0,0,.55)`、分隔线 `rgba(0,0,0,.1)`。

“微信风格”使用这些配色与头像、联系人、消息的阅读顺序，去掉重复角标和玻璃装饰。公开资料面向网页/小程序，未提供桌面通知的精确规格；本项目的圆角、头像、字号及弹窗尺寸属于可自定义的桌面适配，不声称是官方桌面组件的逐像素复刻。

## 设置与兼容

“通知外观”页面可选择“微信风格”或“液态玻璃”。选择液态玻璃后，可单独关闭桌面玻璃效果，或在效果不可用时自动回退普通材质。微信风格默认采用白底与微信配色，颜色、圆角、字号等继续受自定义设置控制，不申请桌面采样、不创建原生玻璃面板。

新配置默认使用微信风格。缺少 `notificationStyle` 的旧配置按液态玻璃迁移，保留原有 `glass` 开关。设置预览与桌面弹窗共用 `NotificationSurface` 和 `NotificationContent`；原生面板和前端共用玻璃参数。

## 自动尺寸

主进程先估算尺寸，渲染进程用实际字体和内联表情宽度校准。标题、时间、未读数量都会参与宽度计算；高度由实际换行后的内容决定，并通过 ResizeObserver 回报主进程。

正常宽度为 288–360 逻辑像素，顶部、底部居中上限为 344；固定宽度模式使用自定义宽度；长正文优先换行，长标题保持单行省略，避免把弹窗横向拉长。四周预留 20 像素，窄屏继续收缩。基础估算高度不超过 320 像素；启用自定义外观时按最大正文行数及可用工作区高度限制；超长内容按可用行数截断。图片表情加载和通知替换会重新测量，关闭事件继续按通知 ID 隔离。

## 点击行为

点击通知仅通过注册的 `weixin://` 协议唤起微信客户端。实机在调用辅助功能接口时再次出现整个微信窗口冻结，现已移除 UI Automation、自动搜索会话、强制焦点与输入队列关联。辅助组件最多运行 6 秒，宿主进程在 8 秒时兜底终止；原有通知仍按 ID 关闭。当前不保证跳转到通知对应会话。

## 验证

在 `source` 中运行：

```powershell
npm test
npm run build
npm run test:ui
```

UI 检查使用隔离配置和确定的示例消息，覆盖短消息、多行/超长内容、长标题、未读数量、窄工作区、玻璃回退、设置切换与保存、关闭按钮以及六个停靠位置。截图和测量结果写入根目录下忽略提交的 `archive/pr1-ui-check/`；测试配置由脚本自动清理。

这些检查不访问微信账号、不采样真实桌面。Windows 原生玻璃实际呈现和真实来信仍需在应用中验收。
